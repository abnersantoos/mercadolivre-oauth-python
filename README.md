# Mercado Livre OAuth 2.0 Integration (Python)

Script simples em Python para realizar o fluxo de autenticação OAuth 2.0 com a API do Mercado Livre e obter o `access_token` e `refresh_token`.

## 📌 Pré-requisitos
* Python 3.x
* Conta de Desenvolvedor e App cadastrado no [DevCenter do Mercado Livre](https://developers.mercadolibre.com.br/devcenter)
* Bibliotecas: `requests`
